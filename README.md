# 🏦 Banking Analysis Dashboard | SQL, Python & Power BI

## 📌 Project Overview
This project focuses on analyzing banking data to explore loan and deposit trends using MySQL, Python, and Power BI. It demonstrates an end-to-end data analytics workflow, from data extraction and exploratory data analysis to interactive dashboard development and business insights.

## 🎯 Objectives
- Analyze banking data using SQL and Python.
- Perform data cleaning and exploratory data analysis (EDA).
- Explore loan and deposit trends.
- Identify relationships between relevant banking variables.
- Develop interactive Power BI dashboards to support data-driven decision-making.

## 🛠️ Tools & Technologies
- **MySQL:** Data extraction and SQL queries
- **Python:** Data analysis and preprocessing
- **Pandas & NumPy:** Data manipulation and numerical operations
- **Matplotlib & Seaborn:** Data visualization
- **Power BI:** Interactive dashboards and reporting
- **Jupyter Notebook:** Exploratory data analysis environment

## 🔄 Project Workflow
1. **Data Extraction:** Retrieved banking data using MySQL queries.
2. **Data Cleaning:** Prepared the data for analysis and addressed data-quality issues where applicable.
3. **Exploratory Data Analysis:** Used Python to explore trends, patterns, and relationships.
4. **Correlation Analysis:** Examined relationships between relevant banking variables and visualized them using a heatmap.
5. **Dashboard Development:** Created Power BI dashboards to analyze loan and deposit trends.
6. **Insight Generation:** Used visualizations to communicate findings and support analytical decision-making.

## 📊 Key Analysis
- Loan-related trends and patterns.
- Deposit-related trends and patterns.
- Relationships between banking variables.
- Visual exploration of financial data through Power BI dashboards.

## 💡 Skills Demonstrated
SQL querying, Python programming, data cleaning, exploratory data analysis, correlation analysis, data visualization, Power BI dashboard development, and analytical problem-solving.

## 🚀 How to Explore
1. Clone or download this repository.
2. Open the available SQL files and execute the queries in MySQL.
3. Open the Python notebook in Jupyter Notebook and run the analysis.
4. Open the Power BI report in Power BI Desktop to explore the dashboards.
